# Engineering Specifications

This workstream translates analysis and architecture decisions into implementation-facing documentation.

The source library includes:
- **Backend SRS**: service behavior and integration specifications.
- **Frontend SRS**: user interface behavior and development specifications.
- **Messaging / MQ SRS**: messaging-related integration requirements.
- **Sequence diagrams**: interactions between components over time.

Use a sequence diagram to communicate a scenario's ordering and component responsibilities, then link the steps to the corresponding detailed specification.

*Source: author's development-specification collection.*
