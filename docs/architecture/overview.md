# Architecture & Design

## High-Level Architecture (HLA)

An HLA describes the system's main components, external integrations and relationships. It provides a shared view for business, engineering and architecture stakeholders and establishes a foundation for more detailed specifications.

Typical elements from the author's HLA guide:
- Major modules, services and external systems.
- Interfaces, data flows and interaction types.
- System boundaries and responsibilities.
- A clear legend and component descriptions.

HLA differs from low-level design: it describes major building blocks and their interactions, not every internal implementation detail.
